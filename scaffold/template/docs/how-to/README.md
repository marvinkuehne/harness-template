# How-to guides

Task-oriented. A how-to guide is a recipe for someone who knows what they want
and has the basics: the steps to reach one goal, in order.

Write here: "how do I do X" with the shortest reliable path.
Not here: teaching from zero (tutorial), full option lists (reference), or the
reasons behind a design (explanation).
