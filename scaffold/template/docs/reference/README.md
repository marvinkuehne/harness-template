# Reference

Information-oriented. Reference is accurate, complete and neutral: facts to
look up while working. It describes the machinery and does not teach or argue.

Write here: every stored document type, API, config key, command and rule, with
exact names, fields and values.
Not here: walkthroughs (tutorial), recipes (how-to), or reasons (explanation).

- [Repo conventions](repo-conventions.md): commit messages, code comments, prose
